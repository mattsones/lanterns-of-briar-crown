# Reference Assets

This folder keeps art that is useful to the project but should not ship through the Vite app bundle.

- `concept/`: early concept art and style candidates.
- `alternates/`: non-selected production-folder variants and master sheets.
- `source-art/`: full-size originals for optimized shipped assets, plus `optimization-manifest.json`.
- `paper-doll/`: archived rig, mask, and equipment proof work. This is reference/prototype material only.

When promoting an image into the game, copy or export a web-ready derivative into `assets/maps/`, `assets/portraits/`, `assets/scenes/`, or `assets/icons/`, then wire that production asset from `src/`.
